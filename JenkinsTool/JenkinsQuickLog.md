# Jenkins 快速日志

将 `JenkinsQuickLog.user.js` 全文粘贴到 Tampermonkey / Violentmonkey 的新脚本编辑器中并保存，然后刷新 Jenkins 页面。与现有 `JenkinsTaskDuration.js` 独立运行。

## 使用

- 在带数字构建号的详情页点击右下角 **⚡ 快速日志**；原有 Console 链接旁也会添加快捷入口。
- 建议从构建详情页进入，避免先展开完整 Console 页面。脚本不会停止已经打开的原生 Console 的加载。
- 默认探测 `logText/progressiveText` 的游标，再读取约 192 KiB 末尾片段；偏移处的首个不完整行会被丢弃。探测会取消响应体，但服务器或代理仍可能生成、缓冲数据；不保证首次请求耗时。
- 使用虚拟滚动：保留完整滚动高度，但只绘制可见行附近的内容（最多 300 行）。长行不折行，可横向滚动。拖动“已加载范围内位置”滑块可直接跳到中间；需要查看整份日志的中间时，先点击“加载全文”。末尾模式的滑块仅覆盖末尾片段，不代表整份日志位置。搜索使用普通文本、不区分大小写，只搜索已加载范围。错误筛选保留前后 3 行；同时输入搜索词时，两者取交集。
- **跟踪新增**每 3 秒读取新增内容，按服务器 `X-Text-Size` 游标继续；结束、出错或关闭后停止。
- **加载全文**可用于前文搜索，单次响应上限 128 MiB；超过上限保留先前内容并提示下载。持续跟踪的文本缓冲也有限制，超过累计上限后暂停跟踪并保留已有内容。片段内行号带 `~`，不是全局行号。
- **原始文本 / 另存为**在新标签打开纯文本，可使用浏览器另存为，再交给本地日志查看器。

## 边界

沿用同域浏览器登录状态，只 GET 日志；不需要 Token 或 Jenkins 服务端插件。通用匹配后仅在具有 Jenkins 页面标识的页面启用，不向第三方发送日志。日志按纯文本显示。

需要 Jenkins 提供标准纯文本 progressiveText 接口及 `X-Text-Size` 响应头。登录失效、重定向、缺失响应头、连续 30 秒无数据超时会显示错误并停止跟踪。首次只读末尾，不代表早期日志没有错误。兼容性仍需在目标 Jenkins 和油猴环境实际验证。

## 1.1.0

增加连续虚拟滚动和范围内百分比跳转。当前不提供服务端任意窗口分页：标准 progressiveText 没有结束偏移参数，不能保证只下载中间小段。全文加载仍有 128 MiB 上限，超大文件建议下载后用本地查看器。

## 1.3.0 搜索跳转上下文

输入普通文本（例如 BI数据统计）后列出匹配行；点击结果或按 Enter 跳到原文位置，保留完整前后文，目标行高亮。Enter / Shift+Enter 或上下一个匹配按钮可循环定位，返回搜索结果按钮恢复结果列表。上下文视图暂时忽略仅错误筛选，保留关键词且暂停跟踪以避免位置被挪走。搜索仍只覆盖已加载范围；查早期内容请先加载全文。

已使用 #51 的真实日志通过模拟 DOM 验证 BI 搜索、点击跳转、前后文、连续匹配与无结果行为；未在真实油猴浏览器中验证。
